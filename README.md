## 功能概览

| 功能 | 说明 |
| --- | --- |
| LANraragi 查重 | 列表页为每个图库显示 `✔`（已收录）、`≈`（高度相似）、`?`（疑似）；点击徽标直接打开库内归档介绍页 |
| 原图 ZIP 下载 | 纯浏览器完成，不依赖 gallery-dl / Python / 本地服务；可选原画或压缩图，边下载边写 ZIP |
| 元数据打包 | ZIP 内可附带 `metadata.json` 与 LANraragi 兼容的 `info.json`；也可只导出元数据 ZIP |

| 无修正标签 | 按图库实际的 `uncensored` 标签显示标记（不靠标题猜），并批量读取页数用于查重提示 |
| 悬浮面板 | 工具与下载两个悬浮球，可拖动、记忆位置，同一时间只开一个面板 |

## 安装方法

### 前置条件

- 浏览器扩展：[Tampermonkey](https://www.tampermonkey.net/) 或 Violentmonkey
- 浏览器基线：Chrome / Edge 67+、Firefox 68+、Safari 14+
  - 下载器的流式写盘依赖 OPFS（Chrome 86+、Firefox 111+、Safari 15.2+）。不支持时会退回内存模式，上限 512 MB，状态栏会标注「内存模式」。

### 方式一：从脚本网站安装

1. 登录 [Greasy Fork](https://greasyfork.org/zh-CN/)，在账户设置里开启成人内容显示。
2. 搜索 **ExHentai Library Toolkit**，打开脚本详情页点击安装。
3. 在油猴管理器中确认，然后刷新 ExHentai / E-Hentai 页面。

成人脚本也可在 [Sleazy Fork](https://sleazyfork.org/zh-CN/) 搜索。这里的账户设置属于脚本网站，与本站无关。

### 方式二：从仓库文件安装（适合测试与自托管）

1. 下载仓库中的 `ExHentai_Library_Toolkit.user.js`。
2. 把文件直接拖进浏览器窗口，或在油猴面板的「实用工具 → 导入」里选择它。
3. 安装后确认脚本版本为 **1.2.0**（工具面板页脚也会显示版本号），刷新页面。

### 更新与卸载

- **更新**：从脚本网站安装的会自动更新；从文件安装的重新导入同名脚本即可覆盖。
- **卸载**：在油猴管理器中删除脚本。如需一并清理设置与缓存，删除后手动清理该脚本的存储数据。

### 从 1.1.x 升级到 1.2.0

- 查重缓存换了命名空间（URL 缓存 `v9`），升级后首次浏览会重新查一遍，旧的未命中缓存不会再被复用。
- 查重失败不再显示红色 `LRR !`：不在库里的条目保持无标记，失败原因只在工具面板状态行汇总。
- 面板页脚的版本号改为运行时读取 `@version`，不再手写。

## 使用方法

### 1. 第一次使用：配置 LANraragi（可选）

查重功能是可选的；只用下载、收藏、搜索等增强功能时无需配置。

1. 点击页面右下角的悬浮球，打开**工具设置**。
2. 填写 **LRR 服务器**，例如 `http://192.168.1.100:3000`（需带 `http://` 或 `https://`）。
3. 填写 **API Key**：LANraragi 启用了密码时必须填写；未启用密码时可留空。
4. 勾选 **启用查重**，按需调整 **主查重并发**（默认 8）与 **备用搜索并发**（默认 2）。
5. 点 **保存并刷新**，页面会重新加载。
6. 点 **测试LRR连接**，状态行会显示 `LRR：在线 · 版本 x.y.z · 归档 N 本`。

> **注意**：API Key 以明文保存在油猴脚本的存储里（`GM_setValue`），并且只在 `Authorization` 请求头中使用，不会写进 URL、ZIP 或控制台日志。请勿把带有 Key 的截图、导出配置发到公开场合。

### 2. 列表页：查看查重结果

打开任意列表页（首页、搜索、收藏夹、标签页等），脚本会自动逐条查询并在标题旁插入徽标：

| 徽标 | 含义 | 建议 |
| --- | --- | --- |
| 绿色 `LRR ✔` | 库里已有源链接匹配的归档 | 可直接跳过 |
| 紫蓝色 `LRR ≈` | 库里存在高度相似的标题 | 点开核对版本/页码 |
| 橙色 `LRR ?` | 库里可能已有，但证据不足 | 点开确认是否同一本 |
| 无标记 | 库里没有，或查重请求失败 | 多为"确实没有"；失败原因见工具面板 |

- **点击徽标**：直接打开该归档在 LANraragi 里的介绍页（`服务器/reader?id=归档ID`）；只有拿不到归档 ID 时才退回搜索页。
- **悬停徽标**：显示判定说明、疑似原因、候选标题、页数对照。
- 缩略图模式下徽标显示在封面左上角，其他模式显示在标题前。

### 3. 页数提示与"删过页"

归档常被删掉开头的汉化组页与尾部广告页，所以页数不一致是**正常现象**：

- 页数**不参与**任何判定，删过页不会导致漏查。
- 悬停提示会并排显示本站页数与库内页数：
  - 差异在约 12%（至少 4 页）以内 → 「可能已删汉化组页或广告页，仍视为同一作品」；
  - 差异更大 → 「可能是不同版本，建议核对」。
- 本站页数来自批量 gdata 请求，需要开启 **无修正标签**；未开启时只显示库内页数。

### 4. 详情页：下载图库

在图库详情页点击下载悬浮球：

1. **压缩包名称**：默认用原文/日文标题，也可切换为英文/中文/罗马音标题。
2. **下载内容**：勾选「下载原画」则取原图，取消则取页面显示的压缩/缩放图。
3. **并行任务**：建议 1–4；数值越大越容易被站点限流。
4. 可选 **检查下载源**：先验证图片页与原画入口是否可用（不下载图片）。
5. 点 **下载当前图库**：图片按 `001.ext`、`002.ext`… 顺序编号，下载完成后自动打包并交给浏览器保存。

行为说明：

- 图片扩展名跟随真实格式（JPEG 为 `.jpg`，PNG/WebP 保留原扩展名，避免转码）。
- 下载/打包未完成时，刷新或关闭页面会弹出浏览器原生确认；取消则继续任务。
- 站点级错误（额度/GP 不足、IP 封禁、账号冻结、HTML 错误页）会立即停止，不会无意义重试；单张图片的瞬时错误会自动重试并换源。
- 浏览器不支持 OPFS 时退回内存模式，上限 512 MB，达到上限会停止并给出明确提示。

**仅获取元数据 ZIP**：在下载面板选好标题类型后点「仅获取元数据 ZIP」，生成的压缩包只含 `metadata.json` 与 `info.json`，不下载图片，也不需要选择本地目录。中文界面文件名前缀为 `[仅元数据]`。

### 5. 收藏、搜索与界面增强

- **快捷收藏**：详情页点击收藏区域、列表页点击「收藏」按钮即可无弹窗收藏；默认收藏夹在设置中配置（0–9）。
- **全局搜索**：列表页顶部出现搜索框，回车跳转到站内高级搜索。
- **翻译高亮**：中文界面高亮中文翻译，英文界面高亮英文翻译。
- **无修正标签**：根据图库真实的 `uncensored` 标签显示「无修正」标记，与查重徽标并排。

### 6. 悬浮面板与油猴菜单

- 两个悬浮球：**工具**（设置与查重）与**下载**（图库下载）。
- 点击悬浮球开关面板，同一时间只显示一个；长按面板标题可拖动，位置会记住。
- 油猴菜单提供同样入口：

| 菜单命令 | 作用 |
| --- | --- |
| ⚙ 打开LRR设置 | 打开工具面板 |
| ⬇ 打开图片 ZIP 下载 | 打开下载面板 |
| 🔄 重新扫描当前页面 | 清除本页相关缓存后重新查重 |
| 📂 重新扫描LRR档案文件夹 | 触发 LANraragi 完整重扫 |
| 🧹 清理LRR缓存 | 清空全部查重缓存 |
| 🟢 测试LRR连接 | 检测服务器状态与归档数 |

### 7. 重扫与缓存

- **重新扫描当前页**：只清当前页涉及的缓存并重查，用于刚入库的作品或怀疑结果过期。
- **重新扫描档案文件夹**：调用 LANraragi 的 Shinobu 重扫接口（`POST /api/shinobu/rescan`），清空文件扫描记录、重启文件监视器并重扫档案目录。**这是重操作**，大库可能持续数分钟：
  - 触发后脚本每 3 秒轮询 `/api/info`，在状态行显示「正在重扫档案文件夹… 索引归档 N 本」；
  - 归档数稳定后提示「重扫已完成」，此时可点「重新扫描当前页」刷新本页判定；
  - 5 分钟仍未稳定会停止轮询并提示到 LANraragi 查看；
  - 失败原因会按 HTTP 状态给出：401/403（Key 不正确或无权限）、404（地址或子路径不对）、400（LANraragi 返回的具体错误）。
- **清空全部LRR缓存**：清掉所有缓存并重扫当前页。

## 查重判定规则

查重分两层，只有确认存在的条目才会出现徽标：

1. **URL 查重**：把图库 URL 的跨站变体依次交给 LANraragi 的 `urlfinder` 插件；命中即 `✔`。命中后还会把库内归档标题登记为可靠别名，协助识别同页其他近似条目。
2. **标题查重**：先用「作者 + 主标题」严格匹配，再用最多 4 个召回查询（含中日文标题的前后片段）宽松匹配。查询词只负责召回，**判定始终使用完整标题**。

判定前先核对"身份"，任一项不一致直接否决：数字/卷话（`Vol.02`、`第2巻`、`第十二話`）、上下卷（含裸写的「作品名 上」）、前后篇、番外、总集篇。

相似度使用字符二元组 Dice + 编辑距离：

| 情形 | 主体长度 | 编辑相似度 | Dice |
| --- | --- | --- | --- |
| 有作者佐证 | ≥ 8 字符 | ≥ 0.88 | ≥ 0.80 |
| 无作者佐证 | ≥ 12 字符 | ≥ 0.94 | ≥ 0.92 |
| 短标题 | 规范化后完全相等 | — | — |

缓存策略：

| 缓存 | 有效期 |
| --- | --- |
| URL 命中 | 30 分钟 |
| URL 未命中 | 5 分钟 |
| 标题已验证命中 | 30 分钟 |
| 标题未命中 / 疑似 | 5 分钟 |

缓存 key 都包含 LANraragi 服务器标识，切换服务器不会串结果。查重失败不会写未命中缓存，也不会在列表上做任何标记；失败原因只在工具面板汇总，并自动重试最多两次。

## 常见问题

**Q：列表上一个徽标都没有？**
A：先确认工具面板里「启用查重」已勾选、服务器地址已填写；再点「测试LRR连接」。如果连接正常但仍无标记，说明这些图库确实不在库里——不在库里就是什么都没有显示。

**Q：明明是同一本，为什么显示 `≈` 而不是 `✔`？**
A：`✔` 要求源链接能对上（跨站 URL 或 gid/token）。如果库内归档来自其他来源、或 LRR 的 urlfinder 插件不可用，就只能靠标题匹配，此时会显示 `≈`。点开核对即可。

**Q：删掉了汉化组页和广告页，会影响查重吗？**
A：不会。页数不参与判定，只会作为提示信息展示（见上文「页数提示」）。

**Q：换了 LANraragi 服务器后，旧结果还在？**
A：缓存 key 含服务器标识，不会复用旧库结论；最多等 5 分钟的未命中缓存过期，或直接点「清空全部LRR缓存」。

**Q：下载到一半失败，或提示被限流/封禁？**
A：脚本会识别额度不足、IP 临时封禁、账号冻结等站点级错误并停止。降低「并行任务」、等待解封后再试；不要用高并发连续下载。

**Q：下载后提示「内存模式」？**
A：当前浏览器不支持 OPFS（如较旧的 Safari/Firefox 或存储被禁用），ZIP 只能在内存里拼装，上限 512 MB。可改用压缩图、减少页数，或换用支持 OPFS 的浏览器。

**Q：点击徽标打开 404？**
A：归档页路径是 `服务器/reader?id=归档ID`。若出现 404，通常是 `LRR 服务器` 地址少了子路径前缀，或该归档已被删除。可先用「测试LRR连接」确认地址。

**Q：点「重新扫描档案文件夹」报 401/404？**
A：401/403 表示 API Key 不正确或 LANraragi 未授权；404 表示地址或子路径不对。若 LANraragi 未启用密码，Key 可以留空。

**Q：会不会请求太多把站点或 LRR 拖垮？**
A：默认主查重并发 8、备用搜索并发 2、下载并行 2，且大量结果命中缓存。若网络或 LRR 较弱，可把并发调低；查询相同标题时请求会合并。

**Q：API Key 存在哪里？安全吗？**
A：存在油猴脚本的存储里（`GM_setValue`），明文保存，仅用于 `Authorization` 请求头。它不会进入 ZIP、URL 或日志；但同浏览器内的其他脚本仍可能读到，请不要在共享浏览器上配置。
