# ExHentai Library Toolkit

**当前版本：1.1.5**

适用于 ExHentai / E-Hentai 的一体化油猴脚本：支持 LANraragi 漫画库查重、原图 ZIP 下载与元数据打包、快捷收藏、搜索以及界面增强。

**简体中文 | [English](README_EN.md)**

---

## 简介

**ExHentai Library Toolkit** 是一个面向 ExHentai / E-Hentai 的一体化油猴脚本，用于增强漫画浏览、下载和本地收藏库管理体验。

脚本将 LANraragi 漫画库查重、纯浏览器原图下载、ZIP 打包、元数据保存、快捷收藏、搜索与界面增强等功能整合到同一个工具中。

## 主要功能

### LANraragi 漫画库查重

- 检查当前画廊是否已经存在于 LANraragi。
- 支持精确匹配与备用搜索。
- 在列表页显示匹配状态，减少重复下载。
- 支持重新扫描与缓存管理。

#### 查重识别方法（1.1.5）

查重依次使用跨站 URL 匹配、作者与标题搜索、标题片段搜索。保持“备用标题搜索”开启可启用标题识别和疑似提示；URLFinder 插件失败时仍尝试标题搜索。

| 标签 | 含义 |
| --- | --- |
| 绿色 `LRR ✔` | 库中存在源链接匹配的归档 |
| 紫蓝色 `LRR ≈` | 库中存在高度相似的标题，需核对版本 |
| 橙色 `LRR ?` | 库中可能已有，标题相似但证据不足，需人工确认 |
| 红色 `LRR !` | URL 查重请求失败，尚未确认库内状态 |

鼠标悬停可查看候选标题和疑似原因；点击标签打开 LANraragi 搜索。标题匹配采用以下规则：

1. **规范化标题**：统一 Unicode 全半角、大小写和括号，去掉零宽字符、压缩包扩展名、活动编号及已知语言／汉化／版本标签。作者只从标题前缀读取，避免把尾部汉化组误当作者；保留书名中的有效词语和方括号副标题。
2. **核对作者**：将 `社团 (作者)` 拆成可匹配的名称，支持只保存社团名或作者名的归档。标题缺作者时，读取 LANraragi 的 `artist:`、`group:` 标签补充证据；两侧都有明确作者但不一致时拒绝命中。
3. **先核对卷话身份**：统一 `Vol. 02`／`第2巻`、`Chapter 12`／`第十二話` 等写法，支持带标签的罗马数字；不同数字、卷话类型、上下卷、前后篇、番外或总集篇不会仅凭高相似度合并。
4. **再计算相似度**：完整作品主体校验同时使用字符二元组 Dice 与编辑距离，保持字符顺序约束。有作者佐证时，模糊匹配要求主体至少 8 字符、编辑相似度 ≥ 0.88 且 Dice ≥ 0.80；无作者佐证时提高为至少 12 字符、≥ 0.94 和 ≥ 0.92。短标题只接受规范化后一致，缺作者时还要求主体至少 6 字符。末尾原作括号可在一侧省略，两侧原作不同则拒绝，长原作名不参与稀释主体差异。
5. **扩大候选召回**：最多尝试 4 个标题查询，包括连续中文／日文标题的前后片段；每个查询最多读取 3 页结果。查询片段只用于寻找候选，最终始终核对完整作品标题。分页参数遵循 [LANraragi Search API](https://sugoi.gitbook.io/lanraragi/api-documentation/search-api)。
6. **避免缓存漏查**：标题缓存升级为 v8，绕过旧规则产生的未命中缓存，并按服务器隔离；相同查询合并并发请求并共享原始候选。原始候选、疑似及未命中结果保留 5 分钟，已验证命中保留 30 分钟；手动重扫会清除当前页的相关查询缓存。索引未就绪、空响应、错误或结果截断不写入最终未命中缓存，旧扫描结果不会覆盖重扫结果。
7. **优先提示可能已有**：未达到 `≈` 条件的候选不再直接丢弃，而是使用更宽松的作者与完整标题相似度条件决定是否显示橙色 `?`。作者一致时可提示较明显的标题变体；作者不明时要求更接近，明确不同作者时仅提示非常接近的长标题。卷号或篇章不同的相似作品也可提示，但会明确注明差异，不算确认重复。同页绿色源链接命中还会建立库内归档与当前画廊标题的可靠别名，立即补标其他近似条目，即使它们此前搜索未命中；不会仅凭相同作者或普通疑似提示传播标签。疑似候选不阻止后续更可靠匹配升级为 `≈` 或 `✔`。

这是 URL 与标题／标签查重，不比较图片内容，也不做跨语言语义翻译。完全不同的译名且没有已确认别名、缺乏可靠作者信息的短标题，或排在查询前三页之外的归档仍可能漏查；`≈` 和 `?` 都建议点击检查归档，`?` 优先提醒可能性，并不代表已经下载该卷或该版本。

### 原图 ZIP 下载

- 直接通过浏览器下载原始图片，也可选择压缩／缩放图。
- 图片按顺序编号保存。
- 下载完成后自动打包为 ZIP。
- 可将 metadata.json 和 LANraragi 兼容的 info.json 一起写入压缩包。
- 压缩包名称默认使用原文／日文标题（没有时回退到默认标题），也可切换为英文／中文／罗马音标题；文件保存到浏览器下载目录。
- 下载或打包未完成时，刷新、关闭或离开页面会请求浏览器原生确认；取消则继续任务，确认离开则中断任务。提示文字由浏览器决定，任务完成或失败后解除提示。

### 仅获取元数据 ZIP

在图库详情页打开下载面板，选择标题类型后点击“仅获取元数据 ZIP”。生成的压缩包只包含 metadata.json 和 info.json，不下载图片，也不需要选择本地文件夹。

中文界面文件名为 `[仅元数据] 图库标题.zip`，英文界面为 `[Metadata Only] Gallery title.zip`。完整图库下载仍使用 `图库标题.zip`。

### 无修正标签

- “中文翻译高亮”旁提供独立的“无修正标签”开关，默认开启，保存设置后生效。
- 根据图库实际的 uncensored 标签判断，不根据标题猜测，也不依赖 LANraragi 查重是否开启。
- 与查重标记并排显示：缩略图模式位于封面左上角，其他列表模式位于标题前。
- 支持动态列表补扫，并通过批量查询和短期缓存减少重复请求。

### 快捷收藏

- 简化收藏操作。
- 在详情页和列表页提供更快捷的收藏方式。

### 搜索增强

- 提供更方便的搜索入口。
- 辅助在网页内容与 LANraragi 本地漫画库之间查找对应项目。

### 浏览与界面增强

- 翻译高亮跟随界面语言：中文界面高亮中文翻译，英文界面高亮英文翻译。
- LANraragi 匹配状态显示。
- 下载相关状态显示。
- 统一悬浮工具面板。
- 快捷收藏、全局搜索、翻译高亮和无修正标签采用两列两行的紧凑布局。
- 合并列表监听、过滤自身标签插入产生的重复扫描，并将下载进度界面刷新限制为每秒最多 10 次；最终状态立即更新。

### 悬浮面板操作

- 点击工具悬浮按钮，打开工具设置并关闭下载面板；再次点击工具按钮关闭工具设置。
- 点击下载悬浮按钮，打开下载面板并关闭工具设置；再次点击下载按钮关闭下载面板。
- 同时最多显示一个面板。鼠标移出或点击面板外部不会关闭，面板内容始终展开，不再自动向上收起。
- 长按标题可拖动面板；点击标题不折叠。切换或隐藏面板不会停止正在执行的下载。

## 安装

请先安装油猴脚本管理器，例如：

- Tampermonkey
- Violentmonkey

### 从脚本网站搜索安装

1. 登录 [Greasy Fork](https://greasyfork.org/zh-CN/) 账户，前往账户设置开启成人内容显示。
2. 搜索 **ExHentai Library Toolkit**，打开脚本详情页并点击安装，在油猴脚本管理器中确认。
3. 安装完成后刷新 ExHentai / E-Hentai 页面。

这里的账户设置属于 Greasy Fork 脚本网站。也可前往 [Sleazy Fork](https://sleazyfork.org/zh-CN/) 搜索成人脚本。

### 从仓库文件安装

然后使用油猴脚本管理器打开并安装：

```text
ExHentai_Library_Toolkit.user.js
```

安装完成后刷新页面即可使用。

## LANraragi 配置

LANraragi 查重功能为可选功能。

如需使用，请在脚本工具面板中填写自己的 LANraragi 地址和 API Key，例如：

```text
LANraragi 地址：
http://192.168.1.100:3000

API Key：
YOUR_API_KEY
```

LANraragi 地址请根据自己的实际部署环境填写。

工具面板中的“重新扫描档案文件夹”会调用 LANraragi 的 Shinobu 重扫接口，清空文件扫描记录、重启文件监视器，并重新扫描 LANraragi 已配置的档案目录。此操作需要配置 API Key；扫描在 LANraragi 服务器后台继续执行。

> 请勿在公开仓库、Issue、截图或其他公开内容中泄露自己的 LANraragi API Key、Cookie 或其他私人凭据。

## LANraragi 匹配状态

```text
LRR ✔
```

表示已经找到较明确的 LANraragi 匹配结果。

```text
LRR ≈
```

表示通过备用搜索找到可能匹配的结果，建议进入 LANraragi 搜索结果进一步确认。

## 1.1.5 更新内容

- 新增橙色 `LRR ?` 疑似已有提示，保留相似但未达到高置信条件的候选，并提供候选标题和差异原因。
- 同页源链接命中可辅助识别其他近似标题，支持先未命中、后命中的异步补标及提示升级。
- 将 URL 查重请求失败与疑似已有分开，失败使用红色 `LRR !`；标题缓存升级为 v8。
- 修复搜索词包裹双引号导致标题漏查的问题：LANraragi 会把它解释为完整标题精确匹配，导致 `彼女催眠4` 无法召回带活动编号、作者及翻译标签的完整标题。使用未加引号的子串查询，并在本地核验完整标题。
- 自动绕过旧查询产生的错误未命中缓存。
- 使用用户反馈的标题增加搜索语义回归测试，覆盖 LANraragi 带引号精确匹配与不带引号子串匹配的区别，以及查询操作符处理。

- 改进标题解析、作者别名与作者标签识别，保留有效副标题并容忍有限错字。
- 增加卷号、话数及篇章身份检查，降低同系列不同作品的误报。
- 增加连续中文／日文片段召回、最多三页候选读取，以及 URLFinder 失败后的标题搜索回退。
- 升级标题缓存、合并重复请求，避免暂时不可用的搜索结果污染未命中缓存。
- 增加标题匹配、分页、异常响应、缓存及失效请求的回归测试。
