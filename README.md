# ExHentai Library Toolkit

**当前版本：1.1.0**

适用于 ExHentai / E-Hentai 的一体化油猴脚本：支持 LANraragi 漫画库查重、原图 ZIP 下载与元数据打包、快捷收藏、搜索以及界面增强。

**简体中文 | [English](README_EN.md)**

---

## 简介

**ExHentai Library Toolkit** 是一个面向 ExHentai / E-Hentai 的一体化油猴脚本，用于增强漫画浏览、下载和本地收藏库管理体验。

脚本将 LANraragi 漫画库查重、纯浏览器原图下载、ZIP 打包、元数据保存、快捷收藏、搜索与界面增强等功能整合到同一个工具中。

## 主要功能

### LANraragi 漫画库查重

- 检查当前画廊是否已经存在于 LANraragi。
- 支持精确匹配与备用搜索。
- 在列表页显示匹配状态，减少重复下载。
- 支持重新扫描与缓存管理。

### 原图 ZIP 下载

- 直接通过浏览器下载原始图片，也可选择压缩／缩放图。
- 图片按顺序编号保存。
- 下载完成后自动打包为 ZIP。
- 可将 metadata.json 和 LANraragi 兼容的 info.json 一起写入压缩包。
- 按“压缩包名称”设置选择默认标题或原文／日文标题，文件保存到浏览器下载目录。
- 下载或打包未完成时，刷新、关闭或离开页面会请求浏览器原生确认；取消则继续任务，确认离开则中断任务。提示文字由浏览器决定，任务完成或失败后解除提示。

### 仅获取元数据 ZIP

在图库详情页打开下载面板，选择标题类型后点击“仅获取元数据 ZIP”。生成的压缩包只包含 metadata.json 和 info.json，不下载图片，也不需要选择本地文件夹。

中文界面文件名为 `[仅元数据] 图库标题.zip`，英文界面为 `[Metadata Only] Gallery title.zip`。完整图库下载仍使用 `图库标题.zip`。

### 无修正标签

- “中文翻译高亮”旁提供独立的“无修正标签”开关，默认开启，保存设置后生效。
- 根据图库实际的 uncensored 标签判断，不根据标题猜测，也不依赖 LANraragi 查重是否开启。
- 与查重标记并排显示：缩略图模式位于封面左上角，其他列表模式位于标题前。
- 支持动态列表补扫，并通过批量查询和短期缓存减少重复请求。

### 快捷收藏

- 简化收藏操作。
- 在详情页和列表页提供更快捷的收藏方式。

### 搜索增强

- 提供更方便的搜索入口。
- 辅助在网页内容与 LANraragi 本地漫画库之间查找对应项目。

### 浏览与界面增强

- 翻译高亮跟随界面语言：中文界面高亮中文翻译，英文界面高亮英文翻译。
- LANraragi 匹配状态显示。
- 下载相关状态显示。
- 统一悬浮工具面板。
- 快捷收藏、全局搜索、翻译高亮和无修正标签采用两列两行的紧凑布局。
- 合并列表监听、过滤自身标签插入产生的重复扫描，并将下载进度界面刷新限制为每秒最多 10 次；最终状态立即更新。

### 悬浮面板操作

- 点击工具悬浮按钮，打开工具设置并关闭下载面板；再次点击工具按钮关闭工具设置。
- 点击下载悬浮按钮，打开下载面板并关闭工具设置；再次点击下载按钮关闭下载面板。
- 同时最多显示一个面板。鼠标移出或点击面板外部不会关闭，面板内容始终展开，不再自动向上收起。
- 长按标题可拖动面板；点击标题不折叠。切换或隐藏面板不会停止正在执行的下载。

## 安装

请先安装油猴脚本管理器，例如：

- Tampermonkey
- Violentmonkey

### 从脚本网站搜索安装

1. 登录 [Greasy Fork](https://greasyfork.org/zh-CN/) 账户，前往账户设置开启成人内容显示。
2. 搜索 **ExHentai Library Toolkit**，打开脚本详情页并点击安装，在油猴脚本管理器中确认。
3. 安装完成后刷新 ExHentai / E-Hentai 页面。

这里的账户设置属于 Greasy Fork 脚本网站。也可前往 [Sleazy Fork](https://sleazyfork.org/zh-CN/) 搜索成人脚本。

### 从仓库文件安装

然后使用油猴脚本管理器打开并安装：

```text
ExHentai_Library_Toolkit.user.js
```

安装完成后刷新页面即可使用。

## LANraragi 配置

LANraragi 查重功能为可选功能。

如需使用，请在脚本工具面板中填写自己的 LANraragi 地址和 API Key，例如：

```text
LANraragi 地址：
http://192.168.1.100:3000

API Key：
YOUR_API_KEY
```

LANraragi 地址请根据自己的实际部署环境填写。

> 请勿在公开仓库、Issue、截图或其他公开内容中泄露自己的 LANraragi API Key、Cookie 或其他私人凭据。

## LANraragi 匹配状态

```text
LRR ✔
```

表示已经找到较明确的 LANraragi 匹配结果。

```text
LRR ≈
```

表示通过备用搜索找到可能匹配的结果，建议进入 LANraragi 搜索结果进一步确认。
